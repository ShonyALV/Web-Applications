# My Site

This project is a multi-page personal website designed to present information about my university, academic background, interests, and student life.

## 👤 Author
* **Jhony Penaherrera** ([ShonyALV](https://github.com/ShonyALV))

## Project Overview

The website includes a home page and several additional sections that provide details about:

- academic courses
- class schedule
- research work
- leadership and club experience
- contact information

## Pages

- **`index.html`** - Main landing page with an introduction and student profile. This page serves as the entry point to the website and features a personal introduction, profile information, and links to navigate to other sections of the site.

- **`pages/courses.html`** - Information about the courses currently being taken. This page displays a comprehensive list of academic courses, including course names, professors, and brief course descriptions related to the student's major.

- **`pages/schedule.html`** - Academic timetable with the class schedule. This page presents the weekly class schedule in an organized format, showing time slots, course names, locations, and other relevant scheduling information to help manage the student's academic calendar.

- **`pages/research.html`** - Research interests and activities. This page highlights current research projects, areas of academic interest, research methodologies, and any involvement in research initiatives.

- **`pages/clubs.html`** - Leadership experience and student organizations. This page showcases participation in student clubs and organizations, leadership roles held, achievements within these groups, and information about the different student communities the person is part of.

- **`pages/contact.html`** - Contact form and contact details. This page provides multiple ways to get in touch, including a contact form for direct messages, email address, date of birthday, degree program, semester, reason for contact, adittional message and accept of terms and conditions.

## How to Use

1. Navigate to the `workshop1/my-site/` folder.
2. Open `index.html` in a web browser.
3. Use the navigation menu to explore the different sections of the website.
