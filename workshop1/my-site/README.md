# My Site

This project is a multi-page personal website designed to present information about my university, academic background, interests, and student life.

## Project Overview

The website includes a home page and several additional sections that provide details about:

- academic courses
- class schedule
- research work
- leadership and club experience
- contact information

## Project Structure

```text
my-site/
├── index.html
├── README.md
├── images/
│   ├── profile.jpg
│   ├── university.jpg
│   ├── ccc.png
│   ├── cs.png
│   └── RussianClub.png
└── pages/
    ├── clubs.html
    ├── contact.html
    ├── courses.html
    ├── research.html
    └── schedule.html
```

## Pages

- `index.html` - Main landing page with an introduction and student profile
- `pages/courses.html` - Information about the courses currently being taken
- `pages/schedule.html` - Academic timetable
- `pages/research.html` - Research interests and activities
- `pages/clubs.html` - Leadership experience and student organizations
- `pages/contact.html` - Contact form and contact details

## How to Use

1. Navigate to the `workshop1/my-site/` folder.
2. Open `index.html` in a web browser.
3. Use the navigation menu to explore the different sections of the website.

## Technologies Used

- HTML
- Static web pages
- Browser-based navigation

## Notes

This is a simple front-end project focused on building a personal university website using static HTML files and internal page links.
